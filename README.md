## Репозиторий для второй лабораторной работы.
1. Файл **HelloWorld.py** содержит практику вывода и ввода текста, а также импортирования сторонних библиотек (datetime);  
2. **square.py** содержит функцию вычисления квадрата любого числа;  
3. **factorial.py** содержит в себе функцию для вычисления факториала неотрицательных чисел.
